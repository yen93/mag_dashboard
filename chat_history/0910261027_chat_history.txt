--------------------------------------------------------------------------------
ASSISTANT:
Traced the mechanism. ga4_ac_contact_source is a derived cache, fully rebuilt by
the Postgres function rebuild_ga4_ac_matches() which does TRUNCATE + INSERT …
SELECT from source tables (activecampaign_contacts, calendly/ga4 staging). That
RPC is called by the ga4-ads-leads-sync edge function, scheduled Mon–Fri 06:00 PH
by pg_cron. So any manually-inserted rows get wiped on the next run because the
rebuild only re-derives matched contacts — it has no knowledge of hand-inserted
rows. Not a backup-restore; a deterministic rebuild from source.
