ac_new_leads.src_lead_channel="Organic Search" for yadao, and that new-paid-leads

Implemented (lower-risk approach — did NOT redeploy the AC-writing edge function):
  • apply_migration "reconcile_calendly_booking_channels" — created SQL function
    public.reconcile_calendly_booking_channels() (SECURITY DEFINER, search_path=
    public): in-place UPDATE ... FROM ac_new_leads setting b.channel =
    a.src_lead_channel where AC has a non-empty value and it differs; Calendly-

  • cron.alter_job(10, ...) → changed calendly-source-sync from "0 22 * * 0-4"

Noted: no dashboard redeploy needed (page reads b.channel, 10-min API cache); the
