     added_at, notes), RLS on, BEFORE DELETE trigger blocks deletes, RPC

     pg_cron job ai-source-patterns-sync-monthly, '0 22 1 * *' (06:00 PH on the 2nd),
     calling the edge function with ?sync=1 via pg_net.
  3. supabase/functions/ai-source-patterns-sync/index.ts (new) — reads existing
     patterns, re-asserts the curated CANONICAL baseline, then asks OpenAI
     (OPENAI_API_KEY, optional OPENAI_MODEL default gpt-4o-mini, temperature 0, JSON

     x.com, bare ai/chat/gpt, etc.). Capped at 30 additions. LLM failure is
     non-fatal. Insert-only. Modes ?dry=1 / ?sync=1 / background. Failure email via
     Gmail, same as the function family.
  4. supabase/functions/ga4-website-traffic-sync/index.ts (edited) — added
     loadAiPatterns(db) which reads active rows from ai_source_patterns; the matcher
