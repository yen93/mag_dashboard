# DESIGN SYSTEM — DESIGN_GUIDE.md summary + mandatory info tools (section 6)
# (Extracted from CLAUDE.md — the dashboard dev reference. Read this when working on the page/area above.)

  **DESIGN GUIDE (as of 2026-11-05):** `DESIGN_GUIDE.md` (repo root) is the dev-facing styling
  standard for the whole dashboard — **`public/roas.html` is the reference**. It codifies the color
  tokens (+ page-local `--x-accent`/`--x-shadow` pattern), typography, the **horizontal segmented
  toggle as THE standard period/filter control** (the ROAS "by FY" pattern — no dropdowns / no
  `3M/6M/12M/YTD` for new work), KPI tiles, the 3 info-tool patterns, tables, chart conventions, etc.
  Read it before restyling or building a page.
  **INFO TOOLS — now MANDATORY + rolled out across the Marketing data pages (as of 2026-11-09):**
  `DESIGN_GUIDE.md` **§6** is the rule: **every card, table and chart carries EXACTLY ONE ⓘ** that, on
  hover/focus, says **what the widget is + where its data comes from** — and that text lives **ONLY** in
  the ⓘ, **never printed in the widget body** (no chart captions, no provenance strap-lines, no
  definition sub-lines; **keep** data values, numeric deltas, `pending` chips, and §4 "as of …" notes).
  The shared helpers are in **`app.js`**: **`infoTip(desc, source)`** (JS-built cards/charts — drop the
  returned span next to the `.label`/heading) and **`fillHeadInfo(root?)`** which fills any
  **`<span class="head-info" data-info="…" data-src="…">`** placeholder (static headings) — call it once
  at init. `roas.html`/`roi.html` are the reference. §6 was extended 2026-11-09 with an explicit
  all-pages SCOPE line + a **cache-bust gotcha** (a page that STARTS using info tools must bump its
  `app.js?v=` or a returning visitor gets a cached older `app.js` lacking `infoTip` → `infoTip is not
  defined`). **The six Marketing data pages — `marketing.html`, `leads_bookings.html`, `spend_roi.html`,
  `content_social.html`, `email_partners.html`, `website_search.html` — were given full §6 coverage and
  bumped to `app.js?v=13`** (website_search was v=12, the rest v=11). Along the way the old native-`title`
  `.kpi-info`/`infoSpan` ⓘ on `marketing.html`/`leads_bookings.html` were migrated to `infoTip`, and two
  dead-wiring bugs were fixed (`email_partners.html` had `head-info` spans but never called
  `fillHeadInfo()`). Frontend-only → needs a **Cloud Run redeploy**.
  **§6 EXTENDED to the last two Marketing sub-tabs + an overflow-clipping fix (as of 2026-11-09,
  later same day):** `nurture_events.html` and `monthly_log.html` were given full §6 coverage —
  **no `app.js` bump needed** (both already load `?v=14`, which carries `infoTip`/`fillHeadInfo`).
  `nurture_events.html`: a `NE_INFO[]` array drives one `infoTip(desc,source)` per KPI card (appended
  to each `.ne-kpi .label` in `renderKpiRow`; `.ne-kpi` got `position:relative` + a hover/focus
  `z-index:2` lift + a flex label), and the Executive X table heading got a `head-info` ⓘ (its old
  bespoke "source: …" caption — both the HTML default and the JS `eventsCap` re-set — was removed).
  `monthly_log.html`: all three table headings (Update status, October notes, Yearly summary) got a
  `head-info` ⓘ and their `.chart-cap` provenance captions were removed; both pages call
  `fillHeadInfo()` at init. **Per-row native-`title` ⓘ inside a scrolling `overflow:auto` table wrap
  are KEPT (an `infoTip` hover card would be clipped/scrolled) — this is now the one sanctioned
  native-`title` exception in DESIGN_GUIDE §6, and such a row icon does NOT count as the table's
  heading-level ⓘ.** **TOOLTIP-CLIP FIX:** the `.src-tip` card is `position:absolute` and escapes
  ABOVE its tile, so an ancestor `overflow:hidden` clips it — `marketing.html` (`.grid .card` + `.kpi`)
  and `spend_roi.html` (`.kpi`) had `overflow:hidden` only to give the 3px `::before`/`::after` accent
  bar clean corners; that was DROPPED and the bar rounded to the card radius (`border-radius:16px 16px 0 0`)
  instead (marketing also got `.grid .card:hover,:focus-within{z-index:3}`). DESIGN_GUIDE §6 gained a
  **"Gotcha (overflow:hidden)"** paragraph + the scrolling-table exception + an expanded all-pages scope
  line (now naming nurture_events/monthly_log/roi/roas and stating pending/sample widgets still get an ⓘ).
  Frontend-only → needs a **Cloud Run redeploy**.
