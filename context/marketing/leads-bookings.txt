# (Extracted from CLAUDE.md — the dashboard dev reference. Read this when working on the page/area above.)

  **Leads & Bookings page (`leads_bookings.html` = Marketing sub-tab "Leads & Bookings", now LIVE as of
  2026-11-05):** a self-rendering page (`initPage('marketing')` with no renderFn +
  `renderMarketingSidebar('leads-bookings')` + its own `fetchJSON`). **As of 2026-11-05 it calls
  `renderMarketingHead(true)`** (right after `initPage`, before the sidebar) → the shared Marketing head
  with NO "Sample data" badge; its old bespoke `.lb-head` header was removed. Same bespoke inline visual layer as `marketing.html`
  (page-local `--mkt-*` tokens, `.segmented` toggle, `.delta`/`.kpi-info`). Top: the **standard `#fySeg`
  FY toggle** (All years + FY22–FY27, default FY27), same placement as the Overview. **Two live data
  sources:** (1) a full-width **"Enquiries by source"** Chart.js **stacked bar** chart + a **"By source"**
  table (Source / Enquiries / Bookings / Rate + Total row) — both from **`GET /api/marketing/leads-by-source`**
  → **`server/metrics/marketing-leads-by-source.js`** (`getMarketingLeadsBySource`, requireAuth, cached
  10 min). **This is ONE union query whose PAID + ORGANIC sourcing deliberately SPLITS by FY** (returning
  per-source-per-month `{ source, month, fyEnd, enquiries, bookings }`):
  **EARLIER FYs (< FY27) — UNCHANGED, from the ROAS view:** **Paid Ads** = `public.roas_counted_deals`
  (rows with `fy_end<2027`; booking = `status='won'`) — one combined Google+Bing row.
  **FY27 ONWARDS — paid + organic come STRAIGHT FROM `ga4_ac_contact_source`** (so the page reconciles with the
  **GA4 & Ads Leads tracker**, **NOT** the Overview card), **EXCLUDING** rows that aren't keynote enquiries —
  either `conversion_link` is a non-keynote funnel page (`EXCLUDED_LINKS` = `/careers-seasonal/`, `/executive-x/`,
  `/careersph-based/`, `/free-gift-opt-in/`, `/leader-x-payment-gateway/`, `/execx/`,
  `/executive-x-payment-gateway/`) **OR** `conversion_action='free_gifts_opt_ins'` (`GA_ACTION_OK` — the SAME
  rule `ac-contact-sources.js` uses; catches the `/free-gift-delivery-page/` variant NOT in `EXCLUDED_LINKS`,
  e.g. `low.victor@gmail.com`): **Google Ads**
  / **Bing Ads** = the **cpc** ga4 rows (`GA_IS_CPC`: `lower(coalesce(channel,source)) LIKE '%cpc%'`) whose
  platform (`GA_PLATFORM`: read from **`channel`** e.g. `"bing / cpc"`, which holds the real platform even when
  `source` is `"(calendly)"`; fallback `source`) is bing/google; booking = `deal_status='won'`.
  **Organic** = `ga4_ac_contact_source` `medium='organic'` (ALL FYs; FY27+ ALSO drops the excluded pages +
  free-gift opt-ins, earlier FYs untouched). **Tailor** = `ac_indirect_deals` `is_tailor=true`; **Bureau** =
  `is_tailor=false`; both EXCLUDE any `deal_id` already in the ROAS view (precedence paid > indirect). The shared
  SQL fragments `GA_PLATFORM` / `GA_IS_CPC` / `GA_LINK_OK` / `GA_ACTION_OK` / `GA_ROW_OK` (+ `EXCLUDED_LINKS`/
  `EXCL_LINKS_SQL`) and `PAID_SPLIT_FY=2027` drive BOTH the counts `SRC_CTE` and the per-lead `LEADS_CTE` — and
  **`PAID_SPLIT_FY` / `GA_PLATFORM` / `GA_IS_CPC` / `GA_ROW_OK` are EXPORTED and RE-IMPORTED by
  `marketing-overview.js`** (see below) so the Overview headline uses the identical FY27 population.
  **GOOGLE-ADS-FLAG ADDITION (2026-11-13):** the union ALSO folds in `public.ac_google_ads_yes_deals`
  (every AC deal with "Google Ads?" = Yes — see the data-stores bullet below) **that isn't already counted**,
  labelled **Paid Ads for FY22–FY26** and **Google Ads for FY27+**. Shared exported `GADS_YES_CTES`
  (`counted_ids` = FY-correct set of deal_ids already counted: roas <FY27 ∪ all `ac_indirect_deals` ∪ FY27+ ga4
  cpc Google/Bing ∪ organic ga4; `gy` = the table minus that set) + `GADS_SRC_ARM`/`GADS_LEADS_ARM` are spliced
  into `SRC_CTE`, `LEADS_CTE` (so range variants too) AND **`marketing-overview.js` imports `GADS_YES_CTES`**
  (collapsed to its 'ads' bucket) so the Overview "Keynote" cards still reconcile. Added vs the prior baseline:
  FY22 +3/+1 won · FY23 +5/+1 · FY24 0 · FY25 +4/0 · FY26 +8/+1 · FY27 +2/+1 (FY27 now 43 enq / 9 booked).
  `marketing-channel-results.js` is unaffected (it filters leads to Bureau/Tailor). Server-only → redeploy.
  **PAID SOURCING REFACTOR (2026-11-16, same feature):** `roas_counted_deals` is now an EXPLICIT paid source for
  **ALL FYs** (not just <FY27), so any roas deal is guaranteed in — fixing e.g. the FY27 won keynote "Tilray"
  (a roas deal with no ga4 cpc row, which previously vanished). Paid precedence is **ga4-cpc (platform authority,
  FY27+) > roas (all FYs) > google-ads-flag**: `GADS_YES_CTES` now also exports a **`ga_cpc_ids`** CTE (FY27+ ga4
  cpc Google/Bing deal_ids), `counted_ids`'s roas arm spans ALL FYs, and the roas paid arm in `SRC_CTE`/`LEADS_CTE`
  (and `marketing-overview.js`'s `paid`) is labelled Paid Ads <FY27 / Google Ads FY27+ **EXCLUDING** FY27 deals
  already in `ga_cpc_ids` (ga4 keeps the Google/Bing split). Aggregate totals are UNCHANGED (roas is the FY27
  superset) — it's a sourcing/robustness change; Tilray now flows through the roas arm as Google Ads FY27 won.
