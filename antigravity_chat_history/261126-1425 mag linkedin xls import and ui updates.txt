2. ZERO-DEPENDENCY BIFF8 .XLS PARSER FOR MAG LINKEDIN EXPORTS
--------------------------------------------------------------------------------
* Problem / Context:
  MAG LinkedIn Company Page exports (`myadventure-group_followers_*.xls`,
  `myadventure-group_visitors_*.xls`, `myadventure-group_content_*.xls`) are
  genuine OLE2 / BIFF8 binary `.xls` files (magic `d0cf11e0a1b11ae1`), while
  `MyAdventure Group_competitor_analytics_*.xlsx` is OOXML `.xlsx`.

* Technical Changes:
  - Created `server/lib/xls-parser.js`:
    Pure-Node OLE2 Compound File Binary + BIFF8 reader (FAT/DIFAT/MiniFAT,
    BOUNDSHEET, SST/CONTINUE, LABELSST, LABEL, NUMBER, RK, MULRK, FORMULA/STRING,
    BOOLERR) returning `{ sheetNames, sheets }` with zero external dependencies.

3. MAG LINKEDIN 4-FILE PARSER & INCREMENTAL MERGE
--------------------------------------------------------------------------------
* Technical Changes:
  - Updated `server/metrics/linkedin-analytics.js`:
    - Auto-detects `.xls` (OLE2) vs `.xlsx` (ZIP/OOXML) by magic bytes.
    - Parses all 4 MAG LinkedIn export formats:
      * Followers (`New followers` + follower `Location`, `Job function`,
        `Seniority`, `Industry`, `Company size` — strictly separated from
        visitor demographics by checking the 2nd column header `Total followers`
        vs `Total views`).
      * Visitors (`Visitor metrics`: daily `pageViews`, `uniqueVisitors`,
        `desktopViews`, `mobileViews` stored in `pageMetrics.dailyVisitors`).
      * Content (`Metrics`: daily `impressions`, `uniqueImpressions`,
        `reactions`, `comments`, `reposts`, `clicks`; `All posts`: post title,
        link, publish date, impressions, engagements, link clicks, `contentType`).
      * Competitors (`COMPETITORS`: date range + `page`, `newFollowers`,
        `posts`, `reactions`, `comments`, `commentsPerDay`).
    - Updated `saveLinkedInImport()` to read any existing `platform_key` row
      and merge it with newly uploaded files via `mergeLinkedInWorkbooks()`,
      allowing users to upload all 4 files together or one-by-one without
      losing prior sheets.
