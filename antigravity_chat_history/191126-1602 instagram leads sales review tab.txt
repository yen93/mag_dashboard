2. BACKEND API, PERMISSIONS & AUDIT LOG MIGRATION
--------------------------------------------------------------------------------
* Technical Changes:
  - Modified `server/users.js`:
    - Added `INSTA_LEADS_REVIEW_EMAILS` (`liv@myadventuregroup.com.au`,
      `julienne@myadventuregroup.com.au`, `james@myadventuregroup.com.au`).
    - Exported `canReviewInstaLeads(email)`.
  - Created `server/metrics/insta-leads.js`:
    - `getInstaLeads()`: reads `public.insta_stories WHERE org IS NOT NULL`
      ordered by `created_at DESC, id DESC`, LEFT JOINing the latest `'set'`
      entry from `public.insta_stories_review_log`. Includes graceful fallback
      when `42P01` (audit log table not yet created) occurs.
    - Classifies rows into:
      - `pending` (`inQueue = true`): `sheet_remark IS NULL AND outreach_status IS NULL`
        (exact match to `leads_for_review`).
      - `send` / `skip` (`inQueue = true`): dashboard-tagged
        `outreach_status IN ('Send intro', 'skip')`.
      - `fromSheet` (`inQueue = false`, read-only): legacy Google Sheet
        backfilled rows (`sheet_remark` `'Send intro'` or `'5A'`).
      - `processed` (`inQueue = false`, read-only): rows whose
        `outreach_status` moved beyond review tags (e.g. `'sent'`, `'contacted'`).
    - `setInstaLeadReview(id, decision, by)`: updates
      `public.insta_stories.outreach_status` (`'Send intro'`, `'skip'`, or
      `NULL` to undo) guarded by `org IS NOT NULL AND sheet_remark IS NULL AND
      (outreach_status IS NULL OR lower(btrim(outreach_status)) IN ('send intro', 'skip'))`,
      then appends an audit row to `public.insta_stories_review_log` (ignoring
      `42P01` until the migration is applied).
  - Modified `server/index.js`:
    - Added `GET /api/sales/insta-leads` (uncached, returns `canReview`).
    - Added `POST /api/sales/insta-leads/:id/review` (gated by
      `canReviewInstaLeads`, validates integer `id` and decision `'send' | 'skip' | null`).
  - Created local SQL migration (not applied directly to DB):
    - `supabase/migrations/20261119160000_insta_stories_review_log.sql`
      defining `public.insta_stories_review_log` (`id`, `lead_id bigint` FK to
      `public.insta_stories(id)`, `decision`, `action`, `set_by`, `created_at`)
      with index `(lead_id, created_at desc)` and RLS enabled.
