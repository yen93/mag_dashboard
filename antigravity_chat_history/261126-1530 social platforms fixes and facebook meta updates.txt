1. EXPRESS BODY LIMIT & JSON API ERROR HANDLER (413 HTML FIX)
--------------------------------------------------------------------------------
* Problem / Context:
  Importing the 4 MAG LinkedIn .xls/.xlsx files (~600 KB base64 JSON) failed in
  the browser with `Unexpected token '<', "<!DOCTYPE "... is not valid JSON`
  because global `app.use(express.json())` had a 100 KB default limit and ran
  before the `/linkedin-analytics/import` route, returning an HTML 413 page.

* Technical Changes:
  - Updated `server/index.js`:
    - Raised global JSON body limit to `app.use(express.json({ limit: '20mb' }))`
      and removed the shadowed route-level `express.json()` middleware.
    - Added an `/api` Express error handler returning `{ error }` JSON instead
      of HTML for unhandled or body-parser errors.

--------------------------------------------------------------------------------
* Problem / Context:
  Multiple tiles and cards on the Facebook tab (Views/Visits, Link clicks,

  chips even though Meta Graph API provides Page/post insights via `read_insights`.

* Technical Changes:

    - Added `/{pageId}/published_posts` + per-post `read_insights` enrichment

      returned in `fbPosts` alongside Instagram `data`.

    - Wired `LIVE.fbTopPosts` from `/api/marketing/meta-top-posts` into both
